Fair-play indicators

These are measurements, not a verdict. Every number below is something you can re-derive from the move table, and every one of them has an innocent explanation as well as a guilty one: short games, forced sequences, pre-moves and blitz all push the same numbers up. One game is never enough to conclude anything, and this page cannot see the things a real investigation uses. If you think someone is cheating, report them to the site and let it look.
