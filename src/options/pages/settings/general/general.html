Engine

The panel button row (bottom left) also has a set-up-position button — the grid icon beside Self-test. It opens a box to paste a FEN: press Enter and that position is analysed instead of the board on the page. While one is set the panel stops following the page so it cannot be overwritten; click the button again (or Re-detect) to return to the live game. An invalid or illegal FEN is refused with a reason.

⚠️ The floating panel is embedded in the web page, which makes the extension easier for a chess site to detect. The toolbar popup runs entirely in the browser and leaves no page footprint — the safer choice for pure analysis. Note: the popup closes when you click the board, so Autoplay and Premove work only with the Floating panel.

Autoplay

Download lichess_db_puzzle.csv.zst from database.lichess.org, decompress it (unzstd lichess_db_puzzle.csv.zst), then pick the .csv here. It is about six million positions, so the import takes roughly half an hour — leave this page open. It only has to be done once, and if it is interrupted nothing is lost: run it again and it picks up what is missing.

Hotkeys

Keyboard shortcuts that work while you're on the game page (they only fire when the floating panel is open). Click a key to rebind it — the next key you press (with any Ctrl/Alt/Shift/Meta) becomes the binding; press Esc to cancel, or Backspace/Delete to clear it. Defaults are single letters; the play-move key is Spacebar. If one clashes with a shortcut the site itself uses, rebind it with any Ctrl/Alt/Shift/Meta combination.
